2 Collect records

Search a database

Runs in your browser. Seven databases answer the page directly. Web of Science and arXiv send no CORS header, so a browser cannot read them; they go through a proxy that you run (app/proxy, free on Cloudflare Workers). Without one, import their export files.

Keys are used for the requests of this search and are not stored. Reloading the page forgets them.

Import export files

RIS, BibTeX, Scopus and Web of Science CSV or plain text, PubMed .nbib, EndNote .enw, Embase, ProQuest and others. The format is detected from the content.

3 Deduplicate

An identifier alone never decides a merge: two records with the same DOI are kept apart when their titles disagree or they sit at different places in the volume. Every merge is logged with its evidence.
