## Robustness to damaged input

Two invariants are asserted for every parser against every corruption mode. **P1**: no unhandled exception -- an import step that dies on one bad file cannot report how many records it found. **P2**: every rejected input unit is counted with a reason, so the "records identified" figure of a PRISMA 2020 flow diagram (Item 16a) can be reconciled against the file.
